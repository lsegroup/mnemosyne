LLM

Connect a provider with its API key, fetch the models that key can really use, then choose which model does which job.

1 Connect a provider

The API key is stored encrypted on the server and is never shown again after saving.

2 Fixed addresses (optional)

Pin a host name to an IP address as a fallback for when the provider's DNS is unstable. Mnemosyne asks DNS first; only when the connection fails (for example EAI_AGAIN, a lookup that did not answer) does it use the address here for that call, and it shows below when that last happened. The certificate is still checked against the host name. Nothing else on the server is changed. If the provider moves to a new address the fallback stops working, so use “Check” after typing it: it shows when the address was last verified.

4 Choose the model and settings for each job

Text

AI call · costs money

Writes the project documentation page from all notes of a project (product description, hardware and software requirements, disaster recovery). Runs when an administrator presses “Generate documentation” and agrees to the cost.

Images

AI call · costs money

Creates the workflow diagram. Step 1: the text model (the one chosen for Text) reads the article and writes a PLAN as data using the two prompts below: an overview picture and, for a bigger system, detail pictures by topic (at most 5 pictures, each with at most 10 boxes and 14 arrows, columns of boxes and the arrows between them). Step 2: the image model chosen here paints every picture of the plan with the instruction for the picture below, which is given every word of the plan. The painted pictures ARE the workflow diagram: they are shown on the project page and in the PDF, and each new run DELETES every earlier diagram and picture of the project. With no image model chosen, Mnemosyne draws the pictures itself from the plan (exact words, no image model). Runs when an administrator presses “Create workflow diagram” and agrees to the cost (the image model is billed per picture, about $0.01 for muse-image-1.0). The limit, sampling values and the two prompts for the plan belong to the text call that writes the plan; the instruction for the picture belongs to the image model.

PDF

no AI call yet

Today the PDF handbook is built from the article and the diagram without any AI call (it costs nothing), so the values below are not used yet and are left empty. They are here, like for the other jobs, so an AI-written PDF handbook can be controlled the same way as soon as it exists: whatever you save now will be used then.

LLM auto

Let Mnemosyne update the documentation by itself at a time when nobody is working. Only projects whose notes changed since their last article are touched; everything else is left alone.

1 When

Set the day and the time. The switch is the kill switch: turned off, nothing runs and nothing is spent.

4 Spending limit and agreement

License

Mnemosyne is open source (Apache-2.0) and free for up to 4 people (5 or more seats need a licence). A licence key lifts the limit and adds the whole Audit history and GitLab sign-in for the admin area. A seat is a person with a GitLab account who uses Mnemosyne, in any role: the first people to sign in take the seats.
